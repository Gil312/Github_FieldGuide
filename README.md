# GitHub Field Guide

An interactive, annotated field guide to the GitHub repository page — built for new coders who want plain-English explanations of every button, tab, and panel without leaving the screenshot.

## What it is

`github-learning-map.html` is a single self-contained HTML file. It embeds a real screenshot of a GitHub repo page and overlays small color-coded dots on every UI element: navigation, collaboration tabs, repo actions, and sidebar info.

- **Hover** a dot to see what that button does and when you'd actually use it, without covering the button itself.
- **Click** a dot to pin its explanation open while you read.
- **Legend filters** let you show or hide a whole category at once (e.g. just the collaboration tabs).
- **"Show all descriptions"** switches to a callout layout: compact cards line up on either side of the screenshot, each connected back to its dot with a thin leader line, so all 30+ explanations are visible at once without overlapping.

## How to use it

No build step, no server, no dependencies. Just open the file in any browser:

1. Download `github-learning-map.html` from this repo.
2. Double-click it (or drag it into a browser tab).
3. Hover or click around the screenshot to explore.

## Why

Reading a GitHub repo page for the first time throws a lot of unlabeled UI at you at once — branches, tags, forks, watch counts, the clone button, Actions vs. Issues vs. Projects. This guide keeps the real interface in front of you while explaining, in plain terms, what each piece does and when a new contributor would actually reach for it.
